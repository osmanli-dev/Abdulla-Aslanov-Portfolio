# APO — портфолио художника

Статичный сайт без сборки: `index.html`, `css/style.css`, `js/`.
Открыть локально: `python3 -m http.server` → http://localhost:8000

## Языки
AZ / EN / RU / TR. Все тексты — в `js/i18n.js` (ключи совпадают с `data-i18n` в `index.html`).
Язык выбирается так: `?lang=xx` в ссылке → последний выбор посетителя → язык браузера → азербайджанский.
Ссылку на конкретный язык можно отправлять: `.../?lang=ru`.

## Работы
Список — в `js/works.js` (порядок в файле = порядок на сайте; первые 12 видны сразу, остальные по кнопке «Показать ещё»).
Добавить работу:
1. Сделать два файла в `images/works/`:
   `magick photo.jpg -resize 1600x1600\> -quality 82 name.webp`
   `magick photo.jpg -resize 720x\> -quality 74 name-sm.webp`
2. Добавить строку в `js/works.js`: `file`, `w`/`h` (размер большого файла), `cat` и название на 4 языках.
